# Revisión visual — interfaz estéreo

> Selección final: **05 — Thunder Deck**. Ver `SELECTED_DESIGN.md`.

Abrir `stereo_concepts.html` en un navegador y elegir uno de los cinco conceptos. La selección queda guardada en el almacenamiento local del navegador.

## Principio elegido para la siguiente fase

El estéreo completo sustituirá la presentación basada en botones genéricos y menús desplegables:

- Pantalla: canción, artista, origen, estado y visualizador.
- Perilla principal: volumen/boost de 0 a 200%, con progresión fría a caliente.
- Botones físicos: anterior, reproducir/pausar y siguiente.
- Controles integrados: ecualizador, perfiles y limitador.
- Luces, espectro y materiales: respuesta visual al estado real; ninguna pieza puramente decorativa se presentará como funcional.

La imagen elegida será dirección artística. La interfaz final se reconstruirá con vistas y controles Android accesibles; no se usará como una imagen estática con zonas táctiles invisibles.

## Conceptos

1. `Zen Neon`: sobrio, elegante, metálico y equilibrado.
2. `City Pop`: luminoso, cálido y retro-moderno.
3. `Midnight Hi-Fi`: nocturno, premium y musical.
4. `Sakura Beats`: anime, suave y expresivo.
5. `Thunder Deck`: industrial, potente y enfocado en boost.
